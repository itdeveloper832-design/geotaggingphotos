How to Check If a Photo Has GPS Coordinates Online

Find out whether an image is geotagged, inspect the EXIF location fields, and decide what to do when the GPS data is missing.

Updated August 2026 · 5 min read

A photo can look ordinary while carrying location information inside its EXIF metadata. Cameras and phones may record latitude, longitude, altitude, and a GPS timestamp at capture time. Editing, exporting, screenshots, and some sharing services can remove those fields. Checking the file before you publish or edit it helps you understand what is actually present.

The quickest browser workflow is to use the online EXIF and GPS Viewer. The viewer reads the selected image locally in the browser and displays the fields it can decode. If coordinates are available, the Photo Location Finder can show the point on a map.

How to check a photo for GPS metadata

1. Open the EXIF Viewer

Open the viewer in a modern browser. You do not need to install desktop software or create an account for the browser workflow.

2. Select the original image

Choose the original JPG, JPEG, PNG, WebP, or TIFF file when possible. A screenshot is a new image and normally does not carry the original photo's EXIF headers.

3. Read the GPS fields

Look for latitude and longitude first. Altitude, GPS time, and a detected place name may also be available. A value such as latitude 40.7128 and longitude -74.0060 is a coordinate pair; it is not the same thing as a typed address stored in a file.

4. Map or repair the result

If coordinates are present, open the Image Location Finder to inspect the map result. If they are absent or incorrect, use Add GPS to Photos to enter known coordinates or replace the existing GPS fields.

What does it mean when no GPS is found?

A missing GPS result does not prove that the photo was never taken at a known place. Location services may have been disabled, the camera may not have had permission, or an export process may have removed metadata. A copied image, screenshot, social-media download, or format conversion may also contain fewer fields than the original.

When you know the correct place, you can add coordinates with the browser tool. When you do not know the place, an EXIF viewer cannot reconstruct it from an empty GPS field. Image-recognition geolocation is a different type of service and should not be confused with reading embedded metadata.

How to interpret the result on another device

Desktop photo applications often expose location in a Details, Info, or Inspector panel, but those panels may show the library's own location record rather than the current file's embedded EXIF. If you are checking a file for publishing, inspect the exact copy that you intend to share. A location shown in a photo app is useful context, but it is not proof that the same coordinates are still present in the exported file.

GPS coordinates are normally represented as latitude and longitude. Latitude ranges from south to north, while longitude ranges from west to east. A coordinate pair can be copied into a mapping service, but a reverse-geocoded street or place name is an interpretation provided by a map service and may require network access.

For a simple verification loop, check the original file in the EXIF Viewer, compare the displayed fields with the place you expect, and then open the Location Finder only if you want a map view. If the values are wrong, do not overwrite the original; create a clearly named edited copy with the Add Geotag tool.

Privacy before sharing a geotagged photo

GPS metadata can reveal a home, workplace, travel route, or other sensitive place. Review the coordinates before posting an original file publicly. The GeoTaggingPhotos image-processing tools are designed to handle selected files in the browser; map tiles and place lookups are separate network features that may be used when you ask to view a location.

If you want to publish a copy without location fields, use the tool's metadata-removal action where supported, or export a verified copy and check it again with the EXIF Viewer.

Frequently Asked Questions

How can I tell if a photo has GPS coordinates?

Open the photo in the free EXIF viewer. It reads the GPS fields and shows the coordinates and the capture location on a map, or it tells you plainly that no GPS metadata was found.

Does a missing GPS result mean the photo has no location?

No. It only means no GPS data is stored in the file. The photo may still show a recognizable place, and some apps and exports strip metadata: screenshots, for example, do not carry the original photo's EXIF data.

Can I check GPS coordinates on my phone?

Yes. The EXIF viewer is a web page, so it works in your phone's browser with no app install. Upload the photo and read the result the same way you would on a computer.

What should I do before sharing a photo publicly?

Check it first. If it carries a location you do not want to share, such as your home or a school, share a copy without that metadata instead, and verify the copy in the viewer again before you post it.
